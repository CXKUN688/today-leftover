安装方法
--------
1. 在手机「设置 → 关于手机」中连续点击版本号，开启开发者选项。
2. 在「开发者选项」中开启「USB 调试」。
3. 用数据线连接电脑，在手机上确认「允许 USB 调试」。
4. 执行：
   <工具链目录>\android-sdk\platform-tools\adb.exe install -r today-leftover-0.1.2-debug.apk

也可直接将 APK 传输到手机后点击安装（需允许「安装未知来源应用」）。
