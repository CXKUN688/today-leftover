# 今日余粮 (today-leftover)

一个完全离线的个人生活费账本 Android 应用。

它回答的问题不是「这个月花了多少」，而是**「照这样花下去，今天还能花多少」**。

<p align="center">
  <em>预算 → 每日额度 → 消费预警 → 账单导入 → 本地备份</em>
</p>

## 功能

- **每日可花额度** — 预算 ÷ 剩余天数，每记一笔即时重算
- **消费预警** — 默认三分之二阈值，每日每级最多提醒一次
- **分类记账** — 支出 / 收入 / 退款 / 内部转账
- **预留资金** — 房租等款项先划出，不占用日常额度
- **账单导入** — 微信 / 支付宝的 CSV 与 XLSX，带预览、去重与确认
- **本地备份** — 版本化 JSON 导出与恢复

> ### ❌ 付款通知自动识别：实测不可用
>
> 微信/支付宝通常不发出本应用可识别的付款通知，**因此不会自动记账**。
> 记账请使用**手动记一笔**或**账单导入**。
> 该功能的代码仍在，应用内也保留了开关，但**当前版本无实际作用**。
> 详见 [使用说明第 7 节](docs/USER_GUIDE.md)。

## 设计原则

- **完全离线** —— 无云同步、无广告、无分析 SDK、无需注册
- **金额用整数分** —— 不做浮点运算，所有加减乘除检测溢出
- **统一入账** —— 所有入口都经过同一套事务，预算与提醒同步更新
- **不谎报能力** —— 未真机验证的通知模板一律只产生「待确认」，不宣称自动记账

## 两种「每天可花」

应用首页同时显示两个金额，回答不同的问题：

| 名称 | 含义 | 何时变化 |
| --- | --- | --- |
| 剩余每天可花 · 含今天 | 可用余额 ÷ 本月剩余天数 | **每次记账后立即重算** |
| 今日额度剩余 | 今日参考额度 − 今天已用普通额度 | 随当天消费变化 |

「今日参考额度」每天只重建一次，因此不会出现「下午首次打开应用，今天的额度被重复扣一遍」的问题。

## 构建

需要 JDK 17 与 Android SDK（platform 36 / build-tools 35.0.0）。

```powershell
# 工具链目录需包含 jdk\ 与 android-sdk\
.\scripts\build.ps1 -ToolRoot <工具链目录>
```

脚本会按 `-ToolRoot` → `$env:DSH_TOOL_ROOT` → `ANDROID_HOME` 父目录 →
同级 `android-toolchain` 的顺序自动探测，找不到会明确报错。

详见 [`docs/BUILD.md`](docs/BUILD.md)。

## 下载安装

前往 **[Releases](https://github.com/CXKUN688/today-leftover/releases)** 页，
在最新版本下方找到 `Assets`，下载 `today-leftover-<版本>-debug.apk`。

或用命令行安装：

```bash
adb install -r today-leftover-0.1.1-debug.apk
```

也可直接把 APK 传到手机上点击安装（需允许「安装未知来源应用」）。

系统要求：**Android 9.0（API 28）及以上**。

下载后建议核对校验值（每个 Release 都附带 `SHA256SUMS-<版本>.txt`）：

```powershell
Get-FileHash .\today-leftover-0.1.1-debug.apk -Algorithm SHA256
```

> ⚠️ Release 中的 APK 使用调试密钥签名，**仅供个人试用**，不是应用商店发布包。

## 已知限制

- **付款通知自动识别不可用**，不要依赖它记账
- XLSX 账单解析只覆盖账单所需结构，非通用 Excel 引擎
- 导入上限：单文件 20 MiB、XLSX 解压 100 MiB、10 万行
- 备份文件含财务数据，请妥善保管；卸载会删除本地账本
